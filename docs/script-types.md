# 脚本类型

[← 返回 README](../README.md)

类型由**全文静态分析**自动判定，判定逻辑见 [工作原理](how-it-works.md)。

| 类型 | 判定依据 | 用途 |
|---|---|---|
| `音源` | 订阅 request 事件并应答 `musicUrl`（方法名或 action 字符串） | **可导入**洛雪音乐 |
| `配套脚本` | 运行时宿主 / user-api preload / 桥接服务 | **不用于导入**，默认视图隐藏 |
| `存疑` | 有部分特征但无法确认 | 需自行判断 |

音源脚本另按注册结构分置信级：结构完整的为**高置信**；仅订阅事件或为混淆脚本
（凭明文头注释识别）的标**待验证**，列表中靠后展示。

## 注意事项

- 类型判定是**静态分析**，不能保证音源的后端接口当前可用；
- 「可用性」仅指**链接可下载**——导入后能否取到歌曲取决于第三方接口现状，需自行实测；
- 本项目不验证音源能否获取平台付费歌曲，详见 README 的「定位与边界」。
